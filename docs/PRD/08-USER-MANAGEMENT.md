# 08-USER-MANAGEMENT.md
# User Management Module Design

## AI English Speaking Platform

**Version:** 1.0  
**Module:** User Management  
**Framework:** NestJS  
**Database:** PostgreSQL + Prisma  
**Cache:** Redis

---

# 1. Overview

## Purpose

User Management Module quản lý toàn bộ thông tin người dùng và hồ sơ học tập.

Responsibilities:

- User Profile
- Learning Goals
- English Levels
- User Preferences
- User Statistics
- User Dashboard
- User Progress Tracking
- User Settings

---

# 2. Business Objectives

Cho phép người dùng:

- Quản lý hồ sơ cá nhân
- Theo dõi tiến độ học tập
- Thiết lập mục tiêu học tập
- Cá nhân hóa trải nghiệm
- Nhận lộ trình học từ AI

# 28. Business Rules

## Rule 1

Email cannot be changed directly.

Requires:

```text
Email Verification
```

---

## Rule 2

English Level updates automatically after assessment.

---

## Rule 3

Avatar must pass validation.

---

## Rule 4

Deleted users become:

```text
SOFT_DELETED
```

---

# 29. Soft Delete Strategy

Instead of:

```sql
DELETE FROM users
```

Use:

```sql
status = 'deleted'
```

---

Benefits:

```text
Auditability
```
